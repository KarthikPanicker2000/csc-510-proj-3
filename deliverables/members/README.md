# Individual Contributions

Each member owns one folder here. Store unreconciled model outputs, personal analysis, test designs, raw-output samples, and prompt notes in the member's folder.

These files are evidence for the cross-model comparison and individual Git history. Team-approved material should be copied or rewritten into `../final/` through a reviewed pull request; do not treat an individual draft as the final submission automatically.

## Expected artifacts per member

- D2 use-case output from the assigned LLM
- D3 proposed test cases or test-code contribution
- selected raw test output produced by that member
- D5 keeper prompts, incorrect model outputs, and evidence used to catch them
- a short model-specific strengths/weaknesses note for this repository
