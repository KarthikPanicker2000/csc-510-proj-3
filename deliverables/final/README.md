# Reconciled Team Deliverables

Only reviewed, team-approved artifacts belong here. The numbered folders correspond to the assignment's D1–D5 rubric.

| Folder | Required content |
|---|---|
| `D1-product-choice` | Product name, original repository URL, team fork URL, and selection rationale |
| `D2-use-cases` | Reconciled 20 unique use cases in the required format |
| `D3-tests-and-results` | Test design, test-code links, selected raw output, and expected-versus-actual results |
| `D4-traceability` | One-row-per-test use-case mapping and critique of the original repository's tests |
| `D5-prompt-notes` | Per-model errors, keeper prompts, comparison matrix, and model-specific reflection |
| `report` | ACM LaTeX source and final PDF submitted to Moodle |
| `demo` | Video link, script, and recording checklist |

Avoid duplicate competing “final” files. When replacing an artifact, preserve its Git history and update the index in the relevant folder.
