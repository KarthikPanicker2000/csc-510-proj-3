# D3 — Tests and Results

Store documentation and curated evidence here. Keep executable tests in `proj2/mealslot/tests/`.

Required D3 material:

- link to the automated test code;
- test-case specification using stable IDs such as `TC-UC04-01`;
- selected raw terminal-output samples;
- results table with test, why it was tried, expected behavior, and what happened;
- explanation and evidence for genuine failures.

Suggested files:

```text
FINAL_TEST_CASES.md
RAW_OUTPUT_P0.txt
RESULTS_TABLE.md
FAILURE_EVIDENCE_INDEX.md
```

Do not commit secrets or every generated Playwright artifact. Preserve a small representative set and link large evidence stored elsewhere.
