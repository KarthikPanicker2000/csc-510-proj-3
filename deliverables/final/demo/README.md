# Demo Video

Store the video link and recording script here. Large video files should normally remain in Google Drive, Panopto, or another approved host instead of Git.

The 2–5 minute video must show, in order:

1. MealSlot running and performing its main function;
2. real automated test output executing;
3. at least one passing and one genuinely failing test;
4. one strong use case demonstrated end to end.

Use a terminal font of at least 18 pt, prepare a short script, and explain the selected failure in one sentence.
