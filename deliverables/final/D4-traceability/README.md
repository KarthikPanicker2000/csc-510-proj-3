# D4 — Traceability and Original-Test Assessment

Required content:

1. one row per new test mapping its test ID to one or more final use cases and stating what it proves;
2. use cases or extensions with no test coverage, with an honest explanation;
3. mapping of the repository's original tests to the final use cases;
4. evidence-based verdict on where the original test suite is blind;
5. original tests that do not map to a user-facing use case.

Recommended files:

```text
TEST_TO_USE_CASE_TRACEABILITY.md
ORIGINAL_TEST_COVERAGE_ASSESSMENT.md
```
